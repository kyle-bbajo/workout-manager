# AI 운동 매니저 — 마커리스 운동 기록

휴대폰 한 대로 PT 수업을 찍으면 **골격(마커리스)으로 동작을 기록·평가**하고, 수업 중 트레이너가 한 말을 **운동별 기록**(운동 이름·기구 세팅·방법·코칭 키워드·회차별 배운 내용)으로 정리하는 웹앱입니다. 트레이너는 스케줄·회원·계약·서명·정산까지 한 앱에서 관리합니다. 회원은 PT가 끝난 뒤에도 혼자 운동을 기록하고 자기 영상으로 자세 평가를 받습니다.

- 시험판 주소: https://kyle-bbajo.github.io/workout-manager/
- 기능 전체 정리: [docs/기능정리.md](docs/기능정리.md)
- 지금은 **시험판**입니다. 서버가 없어 모든 기록은 그 휴대폰 브라우저에만 저장됩니다(아래 ‘한계’ 참고).

## 휴대폰에서 쓰기

1. 휴대폰 브라우저에서 위 주소를 엽니다. 카메라는 https 주소에서만 켜집니다.
2. 홈 화면에 추가합니다.
   - 아이폰: Safari → 공유 → 홈 화면에 추가
   - 갤럭시: Chrome → 메뉴 → 홈 화면에 추가 / 앱 설치
3. 처음 촬영할 때 카메라·마이크 권한을 허용합니다.
4. 오른쪽 위에서 **트레이너 / 회원 / 관리** 화면을 바꿔 볼 수 있습니다(시험판).

## 관리자 · 개발자 (기능 켜기/끄기)

오른쪽 위 **관리**를 누르면 두 탭이 있습니다.

- **기능 관리**: 기능마다 켜기/끄기 버튼. **기본값은 ‘마커리스 운동 추적’만 켜짐**(촬영·골격·반복/세트·자세 점수·운동일지·혼자 운동 영상 평가). 나머지(음성 자막·요약, 코칭 기록, 스케줄, 회원 수업 요청, 회원 관리, 서명, 정산, PAR-Q+, 체지방 목표·인바디, 식단)는 꺼져 있고, 켜면 바로 화면에 나타납니다. 꺼도 기록은 지워지지 않습니다. ‘모두 켜기 / 마커리스만’ 버튼 제공.
- **개발자**: 앱·AI·골격 모델 정보, 저장 용량, 기기 데이터 내보내기·가져오기(JSON), 저장 항목 보기·삭제, 전체 초기화, 오류 기록, 캐시 지우고 새로고침.
- 기능 설정도 그 기기에만 저장됩니다(서버가 생기면 센터·계정 단위로 관리 예정).

## 핵심 기능 한눈에

| 영역 | 내용 |
|---|---|
| **마커리스 자세 평가** | 실시간은 MediaPipe Pose, 녹화·올린 영상 분석은 **RTMPose-m 정밀 모델**(기기에서 실행, 발뒤꿈치·발끝 포함)로 골격을 뽑아 반복마다 관절 각도를 잽니다. **세트별 자세 점수(0~100)**, 반복별 점수, 고칠 점, 다음 무게 제안. 트레이너 기준 동작이 있으면 그것과, 없으면 **일반 기준(골드 스탠다드)**과 비교합니다. |
| **수업 영상 → 운동 기록** | 촬영하면서 말한 내용을 AI(Gemini)가 자막으로 옮기고, 운동별로 이름·중량·기구 세팅(의자·핀·무게·템포)·방법·키워드·이번 회차 배운 점을 정리합니다. 자세 평가·몸풀기도 구간으로 나눕니다. |
| **운동일지** | 기록지 형식: 회차 원, 운동마다 빨간 세트 원(무게)과 횟수·자세 점수, “최고 무게 \| 1RM \| 자세 점수”, 동작 그림, 내 영상 모음. 세트를 눌러 수정, 운동을 눌러 그 구간 영상 재생. |
| **혼자 운동 (PT 없이)** | 회원이 직접 운동·세트를 적고, 세트마다 영상을 올리면 자세 점수와 피드백을 받습니다. |
| **스케줄** | 주간 시간표 + 월간 달력, 수업 중 다음 수업 잡기, 수업 가능 시간 설정, 회원 요청 → 트레이너 승인, 회원 검색, 노쇼 처리. |
| **회원 관리** | 회원 정보(전화·문자 바로 걸기), 운동 목적(목록+직접 입력), 특이사항(부상·건강 등), 체지방 목표, 계약(유료·보너스 횟수, 받은 금액, 할인율, 회당 단가), PAR-Q+ 서명, 운동별 배운 내용, 성과 요약 리포트. |
| **수업 완료 서명** | 트레이너 폰에서 바로 서명 또는 회원 폰으로 서명 링크. 서명하면 수강권 차감·정산 반영. |
| **정산** | 회당 고정 / 매출 비율 / 구간별 비율 중 하나 선택, 보너스 수업 수당, 매출 인센티브·기본급·3.3% 공제, 월별 매출·정산 표(사용 시작한 달부터 전부), 미정산 금액, 남은 수업, 센터 제출용 복사. |
| **식단·인바디** | 음식 사진 칼로리 추정, 인바디 결과지 읽기, 목표 체지방률 → 하루 섭취·운동 칼로리 계산. |

## 운동 그림 · 반복 영상 넣기

`ex/` 폴더에 **운동 이름 그대로** 파일을 넣으면 운동일지 그림 자리에 나옵니다. 우선순위는 `운동 이름.mp4`(소리 없이 반복 재생) → `운동 이름.png` → 앱이 그린 막대 인형입니다. 자세한 규격은 [ex/README.md](ex/README.md).

## 골격 모델

| 용도 | 모델 | 비고 |
|---|---|---|
| 실시간 촬영·미리보기 | MediaPipe Pose Landmarker full (lite 선택) | 빠름 |
| 녹화·올린 영상 분석 (자세 점수) | **RTMPose-m (Halpe26, 256×192)** + ONNX Runtime Web | 더 정확. MediaPipe로 사람 위치를 잡고 그 영역을 RTMPose로 다시 찾음. 처음 한 번 모델 약 56MB + 실행 파일 11~21MB를 받아 기기에 보관. WebGPU가 되면 GPU, 아니면 CPU. 분석은 초당 12프레임 |

- 켜기/끄기: 촬영 화면·개발자 탭의 **정밀 분석 (RTMPose)**. 받을 수 없거나 오류가 나면 자동으로 MediaPipe로 분석합니다.
- 모델 주소는 `config.js`의 `rtmModel`로 바꿀 수 있습니다(직접 올린 파일 사용 등). 기본은 Hugging Face `pocketpose/onnx-models`의 RTMPose(Apache 2.0).
- 결과 화면에 어떤 골격 모델로 분석했는지 표시됩니다.

## 촬영 팁 (자세 평가 정확도)

- 기기를 **옆쪽 2~3m**에 세워 머리부터 발까지 화면에 담습니다(옆모습 기준으로 평가).
- 밝은 곳에서, 화면에 한 명만 크게 나오는 것이 가장 정확합니다.
- 반복은 끝까지 움직여야 1회로 셉니다.
- 자세 점수는 지금 **스쿼트·런지·데드리프트(힙힌지)류**부터 지원합니다. 다른 운동은 영상만 저장합니다.

## AI 설정 (시험판)

- 지금 시험판은 `config.js`에 Gemini 키가 가린 형태로 들어 있어 **회원·트레이너 모두 설정 없이** 음식·인바디·자막 인식을 씁니다.
- 가린 키는 브라우저에서 풀 수 있으므로 **시험이 끝나면 키를 바꾸고**, 실제 서비스는 중계 서버로 옮깁니다.
- 중계 서버(키를 숨기는 방법): `proxy/worker.js`를 Cloudflare Worker로 배포 → 비밀 변수 `GEMINI_API_KEY` 등록(선택 `DAILY_LIMIT`) → 배포 주소를 `config.js`의 `aiProxy`에 넣으면 `aiKey`보다 우선합니다.
- 실서비스 계획: AWS 또는 네이버 클라우드에 서버(회원 계정·기기 간 동기화·AI 중계)를 둡니다.

## 한계 (시험판)

- **서버 없음**: 기록·영상은 그 휴대폰 브라우저(localStorage·IndexedDB)에만 저장됩니다. 브라우저 데이터를 지우면 사라지고, 다른 기기와 자동으로 공유되지 않습니다. 서명·수업 요청·PAR-Q는 **링크를 주고받는 방식**으로 대신합니다.
- **자세 평가 정확도**: 테스트용 가짜 골격으로 흐름만 확인했고, **실제 회원 영상으로 검증·보정이 필요**합니다. 감점 폭은 초기값입니다.
- **음성 요약**: 실제 수업 소리(잡음·여러 사람 목소리)에서의 정확도는 아직 확인 전입니다.
- 시연용 예시 회원(혜원·민준·서연)과 예시 운동일지가 들어 있습니다.
- 동작 안내는 참고용이며 의학적 판단이 아닙니다.

## 파일 구성

```
index.html        앱 전체 (화면 + 카메라·골격 모듈)
config.js         시험판 설정 (AI 키·중계 주소·모델)
proxy/worker.js   Gemini 키를 숨기는 중계 서버 (Cloudflare Worker)
ex/               운동 그림·반복 영상 (운동 이름.mp4 / .png)
docs/기능정리.md   기능·데이터·남은 일 상세 정리
manifest.json     홈 화면 설치 정보
sw.js             오프라인 캐시 (네트워크 우선)
icons/            앱 아이콘
fonts/            Pretendard (SIL Open Font License 1.1)
```
