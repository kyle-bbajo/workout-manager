# AI 운동 매니저 — 마커리스 운동 기록

카메라 한 대를 세워 두면 수업 전체를 골격(스켈레톤)으로 기록하는 웹앱입니다. 운동이 바뀌면 자동으로 나눠 정리하고, 트레이너가 말한 코칭은 키워드로 묶습니다. 회원은 혼자 연습할 때 수업에서 저장한 기준 동작과 비교할 수 있습니다.

## 휴대폰에서 쓰기

1. 휴대폰 브라우저에서 GitHub Pages 주소를 엽니다. 카메라는 https 주소에서만 켜집니다.
2. 홈 화면에 추가합니다.
   - 아이폰·아이패드: Safari → 공유 → 홈 화면에 추가
   - 갤럭시: Chrome → 메뉴 → 홈 화면에 추가 / 앱 설치
3. 처음 촬영할 때 카메라와 마이크 권한을 허용합니다.

## 지금 되는 것

| 기능 | 내용 |
|---|---|
| 실시간 골격 인식 | MediaPipe Pose Landmarker(lite)를 기기에서 실행합니다. 영상은 서버로 보내지 않습니다. |
| 운동 자동 분할 | 고관절·팔꿈치 각도로 반복을 찾습니다. 동작은 스쿼트 계열, 힙힌지, 당기기, 머리 위 밀기, 기타로 나눕니다. 쉬는 시간이 길면 다음 세트로 기록합니다. |
| 동작 분석 | 스쿼트 깊이와 상체 각도, 힙힌지 무릎 굽힘, 로우 반동, 프레스 허리 젖힘을 봅니다. |
| 운동 이름·자막·키워드 | 촬영 중 “스쿼트 60킬로”, “다음은 데드리프트”처럼 말하면 그 이름으로 구간을 나눕니다. 촬영이 끝나면 영상 속 말소리를 AI(Gemini)가 자막으로 옮기고, 운동마다 이름·중량·코칭 특징을 키워드로 정리합니다. 운동별 영상 구간에 자막이 함께 나옵니다. |
| 트레이너 판단 반영 | 반복 직후 “더 앉아요”라고 하면 그 깊이를 부족으로 보고 회원 기준을 조정합니다. |
| 개인정보 | 촬영 중 얼굴과 다른 사람은 모자이크 처리합니다. 녹화본도 모자이크된 화면입니다. |
| 수업 기록 저장 | 정리된 수업은 이 기기에 자동 저장되고(영상 포함), 수업 탭의 ‘저장된 수업’에서 다시 열 수 있습니다. |
| 기준 동작 저장 | 수업 정리에서 좋은 반복을 기준 동작으로 저장합니다(이 기기 브라우저에 저장). |
| 혼자 연습 | 기준 동작을 점선으로 겹쳐 보여 주고, 일치도를 계산합니다. 다르면 트레이너 멘트를 음성으로 안내합니다. |
| 음식 사진 인식 | 카메라로 찍거나 앨범에서 고르면 AI가 음식·양·칼로리를 추정합니다. 끼니 몫에 맞춰 사진 위에 ‘여기까지’ 선을 그어 줍니다. 기록은 이 기기에 날짜별로 저장됩니다. |
| 인바디 결과지 읽기 | 결과지 사진이나 인바디 앱 캡처에서 체중·골격근량·체지방량·기초대사량·기종·측정 시각을 읽어 채웁니다. 확인 후 저장하면 목표 계산에 반영됩니다. |
| 시연 모드 | 카메라가 없을 때는 미리 만든 동작으로 전체 흐름을 보여 줍니다. |

## 아직 시연용인 것

- 회원·스케줄·정산 화면은 예시 데이터를 씁니다.
- 서버가 아직 없어 기기 간 공유가 되지 않습니다. 기준 동작은 같은 기기, 같은 브라우저에서만 이어집니다.
- 혼자 연습의 트레이너 목소리는 합성음으로 대신합니다. 실제 앱에서는 수업 녹음 클립을 재생합니다.
- 카카오톡은 요약 텍스트를 공유하거나 복사하는 방식입니다.

## 시험판 공용 AI (키 입력 없이 쓰기)

`config.js`의 `aiProxy`에 중계 서버 주소가 들어가 있으면, 앱을 연 누구나 키 없이 음식·인바디·자막 인식을 쓸 수 있습니다. Gemini 키는 중계 서버(Cloudflare Worker)의 비밀 변수에만 두고 저장소에는 넣지 않습니다.

1. aistudio.google.com → Get API key로 Gemini 키를 만듭니다 (결제 연결 안 한 프로젝트 권장).
2. dash.cloudflare.com → Workers & Pages → Create → Worker를 만들고, `proxy/worker.js` 내용을 붙여 넣어 Deploy합니다.
3. Worker → Settings → Variables and Secrets → `GEMINI_API_KEY`를 **Secret**으로 추가합니다. (선택: `DAILY_LIMIT` 하루 요청 수, 기본 300)
4. 배포된 주소(`https://○○.workers.dev`)를 `config.js`의 `aiProxy`에 넣습니다.

## AI 연결 (음식·인바디 인식)

내 정보 → AI 연결에서 모델을 고르고 API 키를 한 번 넣습니다.

- Gemini: aistudio.google.com → Get API key (무료 사용량 있음)
- Claude: console.anthropic.com → API Keys

키는 이 기기 브라우저에만 저장됩니다. 사진은 고른 AI 회사로 보내져 분석됩니다. 서버가 생기면 키를 서버로 옮길 예정입니다.

## 촬영 팁

- 기기를 옆쪽 2~3m에 세워 머리부터 발까지 화면에 담습니다.
- 밝은 곳에서, 화면 중앙에 한 명만 서는 것이 가장 정확합니다.
- 반복은 끝까지 움직여야 1회로 셉니다.

## 파일 구성

```
index.html        앱 전체 (화면 + 카메라 모듈)
config.js         시험판 설정 (공용 AI 중계 주소)
proxy/worker.js   Gemini 키를 숨기는 중계 서버 (Cloudflare Worker)
manifest.json     홈 화면 설치 정보
sw.js             오프라인 캐시 (네트워크 우선)
icons/            앱 아이콘
fonts/            Pretendard (SIL Open Font License 1.1)
```

## 배포 (GitHub Pages)

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save. 1~2분 뒤 `https://<아이디>.github.io/workout-manager/` 에서 열립니다.
