# AI 운동 매니저 — 기능 정리 (2026-11-04 기준)

시험판(GitHub Pages)에서 실제로 돌아가는 기능을 화면별로 정리했습니다. “시연”은 예시 데이터로만 보이는 부분입니다.

---

## 0. 관리자 · 개발자 (기능 켜기/끄기)

- 오른쪽 위 **관리** → **기능 관리 / 개발자** 탭.
- **기본값: 마커리스 운동 추적만 켜짐.** 나머지 10개 기능(음성 자막·요약, 코칭 기록, 스케줄, 회원 수업 요청, 회원 관리, 수업 완료 서명, 정산, PAR-Q+, 체지방 목표·인바디, 식단)은 버튼으로 켬.
- 마커리스만 켜져 있을 때: 트레이너는 홈·수업 탭(회원 골라 촬영, 저장된 수업, 운동일지), 회원은 홈·운동 노트·오늘 운동 탭(혼자 연습, 운동일지·세트 영상 평가)만 보입니다. 음성 자막·요약이 꺼져 있으면 촬영 후 AI 정리를 하지 않습니다.
- 꺼도 기록은 남고, 다시 켜면 그대로 나옵니다. 저장 키 `aiwm_flags`.
- 개발자: 앱·AI·골격 모델 정보, 저장 용량, 데이터 내보내기/가져오기(JSON, 영상 제외), 저장 항목 삭제, 전체 초기화, 오류 기록, 캐시 지우고 새로고침.

## 1. 마커리스 동작 기록 · 자세 평가

### 촬영
- 첫 화면에서 실제 카메라 미리보기에 골격과 무릎·고관절 각도를 보여 주고, 전신·옆모습이 맞는지 확인한 뒤 같은 카메라로 바로 촬영합니다.
- 골격 모델: 실시간은 MediaPipe Pose Landmarker **full**(기본), lite(선택). **녹화·올린 영상 분석은 RTMPose-m(Halpe26) 정밀 모델**: MediaPipe가 사람 영역을 잡고 그 영역을 RTMPose로 다시 찾아 관절 좌표를 바꿔 넣음(발뒤꿈치·발끝 포함). ONNX Runtime Web, WebGPU 우선·CPU 대체, 처음 한 번 약 56MB(저장소 `models/`, OpenMMLab 공식 파일) + 실행 파일(`vendor/ort/`), 실패하면 단계별 오류를 보여 주고 MediaPipe로 자동 대체. 개발자 탭에서 상태(실행 장치·정규화 방식·프레임당 시간) 확인.
- 흔들림 줄이기: One Euro 필터 + 잠깐 안 보이는 관절은 직전 값 유지. 두 사람이 잡히면 가장 크게 보이는 사람을 회원으로 봅니다.
- 얼굴·다른 사람 모자이크(녹화본 포함).

### 반복 · 운동 나누기
- 고관절·팔꿈치 각도로 반복을 찾고, 쉬는 시간이 길면 다음 세트로 기록합니다.
- 말로 부른 운동 이름(“다음은 데드리프트”)으로 구간을 나눕니다. 운동 이름은 기본 라이브러리(136개)에서 먼저 찾습니다.

### 자세 평가 (옆모습 기준)
- 반복마다 가장 깊은 순간의 **발목(정강이 기울기)·무릎·고관절·상체 각도·엉덩이 위치·허벅지 각도**를 잽니다.
- **비교 기준**
  - 트레이너가 수업에서 저장한 **기준 동작**이 있으면 그것과 비교
  - 없으면 **일반 기준(골드 스탠다드)**
    - 스쿼트: 허벅지 수평 이하 · 상체와 정강이 기울기 차이 ±15° · 정강이 20~40° · 상체 55° 이하
    - 힙힌지(루마니안 데드리프트 등): 무릎 10~35° · 상체 50° 이상 숙임 · 엉덩이 충분히 뒤로
- **세트별 자세 점수(0~100)**: 반복마다 100점에서 기준을 벗어난 만큼 감점 → 세트 평균
  - 85점 이상 좋음(초록) · 70~84 주의(주황) · 70 미만 교정(빨강)
  - 반복별 점수, 가장 낮은 반복, 고칠 점(“허벅지가 수평이 될 때까지 더 앉으세요” 등)
  - 평균은 괜찮지만 일부 반복이 흔들리면 몇 번째 반복인지 알려 줌
- **다음 무게 제안**: 무게와 점수를 같이 봄
  - 무너진 세트가 있으면 “60kg에서 자세가 무너졌어요 → 다음엔 55kg에서 자세 먼저”
  - 모두 좋으면 “다음엔 +5kg(하체) / +2.5kg(상체) 도전”
  - 주의 세트가 있으면 “같은 무게 유지”
- 지원 운동: 스쿼트·런지·스플릿 스쿼트·데드리프트·힙힌지류. 그 밖의 운동은 영상만 저장.
- ROM(가동범위)은 각도 대신 **처음 대비 %**로 보여 줍니다.

## 2. 수업 영상 → 운동 기록 (음성 요약)

- 촬영 중 소리를 따로 녹음 → 촬영이 끝나면 Gemini가 자막으로 옮김(긴 수업은 4분 단위로 나눠 처리).
- 운동마다 정리: **운동 이름 · 종류(자세 평가/몸풀기/운동) · 중량 · 기구 세팅(기구·의자·핀/칸·무게·가동범위·템포·세트·주의) · 방법 · 코칭 키워드 · 이번 회차 배운 점**
- 운동별 영상 구간 재생 + 자막.
- 기구 세팅은 회원 앱 **‘내 기구 · 운동 세팅’**에 남아 혼자 운동할 때 그대로 맞춥니다.
- 이번 회차 배운 점은 회원의 **운동별 배운 내용**(1회차 힙힌지, 2회차 무게중심 이동 …)에 자동으로 쌓입니다.
- 저장된 수업: 다시 열기, 영상만 지우기, 전체 삭제, 사용 용량 표시.

## 3. 운동일지

- 형식: 어두운 기록지, 맨 위 회차 원, 운동마다
  - 이름 / “최고 무게 | 1RM(추정) | 자세 점수”
  - 빨간 세트 원(무게) + 아래 횟수 + 자세 점수(테두리 색)
  - 다음 무게 제안 한 줄, 메모
  - 오른쪽 동작 그림(또는 반복 영상), 아래 내 영상 모음
- 세트 원을 누르면 무게·횟수 수정·삭제, 그 세트 자세 상세, (혼자 운동) 그 세트 영상 올리기·보기.
- 운동 칸을 누르면 그 수업에서 해당 운동 구간만 재생 + 동작 그림과 **내 골격**을 나란히, 기준 대비 표.
- 추정 1RM = 무게 × (1 + 횟수 ÷ 30).
- 보내기(카카오톡 등 공유/복사).
- 동작 그림: `ex/운동 이름.mp4`(반복 영상) → `.png` → 앱이 그린 막대 인형 순서.
- 위치: 회원 앱 ‘오늘 운동’·‘운동 노트’, 트레이너 회원 화면, 저장된 수업의 ‘일지’ 버튼.

### 혼자 운동 (PT 없이)
- ‘오늘 운동 기록하기 · 혼자 운동’ → 운동 추가(라이브러리 자동완성) → 세트 입력.
- 세트마다 영상을 올리면 그 세트의 자세 점수·피드백. 영상은 기기에 저장.

## 4. 스케줄

- 주간 시간표(기본) + 날짜 버튼으로 월간 달력 드롭다운.
- 빈 칸을 눌러 수업 잡기, 매주 반복·남은 횟수만큼 한 번에, 겹침 알림.
- 촬영 중·수업 정리 화면에서 ‘다음 수업 잡기’.
- **수업 가능 시간** 설정(요일별·휴게 시간), 시간 밖은 회색.
- **회원 수업 요청 → 트레이너 승인** 후 확정(겹치면 승인 불가, 거절 사유).
- 수업 잡기에서 **회원 검색**(이름·전화번호 뒷자리, 특이사항 표시).
- 노쇼 처리(수강권 차감·정산 포함 여부는 규칙으로 선택).

## 5. 회원 관리

| 카드 | 내용 |
|---|---|
| 회원 정보 | 휴대폰(전화·문자·복사), 성별·만 나이, 생년월일(숫자로 입력: 19920514·920514), 키, **운동 목적**(목록 12개 + 직접 입력), 등록일, 수강권, 계약 금액·회당 단가 |
| 체지방 목표 | 현재 체중·체지방률(혜원은 인바디) → 목표 체지방률·기간 → 목표 체중·빼야 할 체지방·주당 감량(체중의 1% 초과 경고)·하루 적자·섭취/운동 목표. 트레이너가 정하거나 회원이 직접 정함(누가 언제 정했는지 표시), 회원 앱 목표와 연동 |
| 특이사항 | 부상·통증 / 건강·약 / 성향·선호 / 일정·연락 / 기타, 날짜, 맨 위 고정, 삭제. 부상·건강이 있으면 회원 목록에 ‘특이사항’ 표시 |
| 수강권·계약 | **유료 횟수 + 보너스 횟수**, 실제 받은 금액, 정가(할인율 자동), 회당 단가 = 받은 금액 ÷ 유료 횟수, 지금 회차가 유료/보너스인지, 재등록 계약 추가 |
| PAR-Q+ | 회원이 앱에서 작성 후 서명 제출, 트레이너가 내용 확인·작성 요청 |
| 운동별 배운 내용 | 운동별·회차별 배운 점과 단계(1 처음 배움 ~ 5 숙련), 수업 영상에서 자동 추가, 직접 고침 |
| 성과 요약(재등록 리포트) | 몸·출석 + **배운 운동 전체 운동별 평가**(처음→지금·단계·배운 회차·코멘트), 전체 스킬 종합, 총평, 다음 목표. 모든 칸 수정, 운동 추가/빼기, 카카오톡 보내기 |
| 서명 기록 | 회차·시각·서명 이미지 |

## 6. 수업 완료 서명

- 트레이너 휴대폰에서 바로 서명, 또는 회원 휴대폰으로 서명 요청 링크.
- 서명하면 수강권 차감, 정산에 반영. 홈 타일 ‘오늘 수업 / 수업 완료 / 이번 달 정산’을 누르면 누구·몇 회차·수업 시각·서명 시각까지.

## 7. 정산

- **정산 방식(하나만 선택)**: 회당 고정 수당 / 매출 비율(%) / 구간별 비율(이번 달 수업 수에 따라, ‘도달 구간 전체 적용’ 또는 ‘구간별 누진’)
- 회원마다 회당 단가가 다름(할인 반영). **보너스 수업**은 매출 0, 수당은 ‘지급 안 함/회당 단가로 지급’ 선택.
- 그 밖의 급여 항목: 등록 매출 인센티브(%), 기본급, 3.3% 원천징수(실수령 보기).
- **월 정산 요약**: 등록 매출(신규/재등록) · 수업 매출 · 나의 정산 금액, 지급 완료 처리(그때 금액으로 고정).
- **월별 매출·정산 표**: 사용 시작한 달부터 모든 달, 연도별 합계·전체 합계, 상태(진행/미정산/완료/기록 없음), 아직 안 받은 정산 금액·횟수, 받은 정산 합계.
- **남은 수업**: 회원들이 결제하고 아직 안 한 수업 횟수·금액·예상 수당.
- 센터 제출용 내역 복사(매출·정산 항목·등록 내역·미정산·남은 수업·수업 내역).

## 8. 식단 · 인바디

- 음식 사진 → AI가 음식·양·칼로리 추정, 끼니 몫에 맞춰 ‘여기까지’ 선.
- 인바디 결과지 사진/앱 캡처 → 체중·골격근량·체지방량·기초대사량·기종·측정 시각.
- 목표 체지방률·기간 → 빼야 할 체지방(×7,700kcal), 하루 적자, 섭취 목표(하한 보호), 운동 소비 목표.
