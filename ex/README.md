# 운동 그림 · 반복 영상 폴더

이 폴더에 **운동 이름 그대로** 파일을 넣으면 운동일지의 동작 그림 자리에 나옵니다.

| 넣는 파일 | 보이는 방식 |
|---|---|
| `운동 이름.mp4` | 소리 없이 자동으로 계속 반복 재생 (우선) |
| `운동 이름.png` | mp4가 없을 때 그림 |
| 둘 다 없음 | 앱이 그린 막대 인형 |

예: `스쿼트.mp4`, `루마니안 데드리프트.mp4`, `힙 어브덕션.png`

- 이름은 앱에 표시되는 운동 이름과 띄어쓰기까지 같아야 합니다.
- 반복 영상 권장: 정사각형(예: 480×480), 2~4초, H.264 mp4, 소리 없음, 파일 1MB 이하.
- 자세 평가는 그림·영상과 상관없이 회원이 올린 영상의 골격(마커리스)으로 합니다.
